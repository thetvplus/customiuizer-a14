# A14 任务系统

## 目录

```text
tasks/
├─ active/       当前正在执行；通常只允许一个主要任务
├─ backlog/      已确认但尚未启动
├─ blocked/      仅外部依赖导致的阻塞
├─ completed/    已完成任务的精简记录
└─ TASK_TEMPLATE.md
```

## 任务类型

- `FIX`：修复明确缺陷；
- `FEATURE`：增加用户可见能力；
- `OPTIMIZE`：行为基本不变的性能、耗电、稳定性或结构优化；
- `PORT`：在 A13/A14 之间移植功能或修复；
- `INFRA`：构建、测试、发布或工具链；
- `DOCS`：仅限真正需要独立交付的文档工作。

## 基本规则

1. 一个目标只有一个任务合同；
2. 不创建 `REVIEW-*` 和 `IMPLEMENT-*` 对；
3. Review 反馈回到原任务；
4. 任务文件不锁死普通开发 HEAD；
5. 任务完成后只保留结果、证据和未解决限制；
6. completed 任务不再作为默认 Agent 上下文；
7. ROADMAP 只引用任务名，不复制任务全文。
