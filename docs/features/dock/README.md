# Dock 与模糊

[页面功能地图](../../FEATURE_MAP.md) · [待验收与证据](../../maintenance/A14_REFINEMENT_ROADMAP.md)

入口为「桌面 → Dock」。背景默认关闭，修改后重启桌面。「背景尺寸微调」同时调整上下和左右：正值四边扩展、负值四边收缩，默认 0 dp（存储值 17，减去偏移 17）；按 Dock 可用空间和导航安全区对称限幅，图标仍使用原生位置与大小。全宽底栏隐藏圆角、水平间距和尺寸微调参数；有效旧高度与上下边距键保持兼容。

自动圆角沿用 main 的面板比例：以桌面原生面板半径为尺度，屏幕底部物理圆角只作上限，浅面板最多取半高的 64%，避免趋近胶囊。DockCornerGeometry 统一决定半径及原生圆角矩形外轮廓，三种材质及液态 → 磨砂 → 纯色的降级共用同一布局和轮廓，不在各材质内重新推算。手动半径和全宽直边规则保留；有效设备圆角缓存至配置 / Insets 变化，临时缺失不重置。

按当前产品选择，玻璃外轮廓与磨砂共同使用原生圆角矩形；自绘填充、玻璃裁切及原生模糊边界使用同一尺寸和半径。玻璃继续采样壁纸并保留清透中心、折射、色散与边缘高光，内容不改成磨砂。折射距离与法线改为同一圆角矩形的解析结果，取消旧 G4 法线纹理，避免外轮廓改圆后内部折射仍沿另一种曲率。G4 仅用于有界内缩装饰，不作为第二层外轮廓；动态岛的 G4 胶囊保持原规则。路径只在尺寸 / 半径变化时更新。

| 机制 | 开关与失效范围 |
| --- | --- |
| Android BlurController | 模块 `system_disable_window_blurs` 与系统 `disable_window_blurs` 取 OR；不覆盖用户开关 |
| Launcher BackdropBlurRelativeLayout | 私有材质可能选择 Google 跨窗口或 MIUI 后端；支持能力不等于当时有模糊 |
| DockGlassBackdrop / Optics | 仅采样壁纸合成层并以 Shader 绘制，不是全局窗口模糊，不采集应用窗口 |
| 状态栏 RenderEffect | 模块自己的短时覆盖画面；模块禁用模糊时使用 alpha |

桌面 Dock 可选全宽底栏、原生材质和壁纸采样玻璃，图标位置与点击范围保持。采样每个装饰最多一张受尺寸限制的纹理、一个在途请求；动态壁纸刷新最多 30 Hz，隐藏停止。静态壁纸只响应真实位置 / 来源失效，并保留 450 ms 有界原生动画跟随；稳定后无额外采样定时任务，不为桌面时钟或图标的无关绘制重复采样。可见裁剪只使用同一缓存的原生圆角矩形路径，折射按同一边界解析法线，不做曲线积分或逐像素搜索。透明内部复用一次纹理采样，仅边缘色散增加采样。壁纸纹理有效时关闭该 Dock 的原生模糊底层；纹理 / Shader 失败则只保留原生材质，不叠两份底色。采样空帧或暂时异常按当前可见代最多在 64 / 160 / 400 ms 后重试，仍不可用则等待真正的来源 / 可见性变化；Shader 或无效纹理失败仍退役镜片并使用原生回退；替换、隐藏、配置失效及 detach 释放 Bitmap / Shader / 回调。不为 Dock 重新开启全局模糊，也不因静态检查宣称更流畅。

背景加入 `HotSeats.getUserPresentAnimationChildList()` 返回的原生参与者列表，由 Launcher 自己准备、驱动与重置解锁动画。全宽背景保留根容器布局，通过一个随 HotSeats 释放的无交互容器继承位移、缩放及透明度；原生解锁属性和父级变换分别持有。编辑动画先完成原调用，再核验关联的 Dock 弱引用；没有有效 owner 时直接返回原结果，不读取 Transformation 参数。有 owner 时只读取原生已经求得的 Transformation，不再次推进动画；`getTransformation=false` 的原生终帧仍保留矩阵与 alpha，等宿主清除 / 替换动画后的下一次预绘制才退休，避免捏合松手时提前弹回底部。矩阵恢复不会覆盖原生属性。壁纸采样使用包含该容器动画矩阵的实际视觉坐标。此修复有 ROM 声明 / Smali 与主机逐进度回归，真实锁屏、远程过渡、帧时间和材质效果仍待实机。


2026-10-18 的 fuxi CN / TW 两份离线样本具有相同 `MiuiHome.apk`（`RELEASE-4.39.30.8604-08262248`）。安装点为 `HotSeats.updateContent()` 与 `onWallpaperColorChanged()`；自动材质复用宿主模糊 / 混色，系统模糊只接受圆角矩形，保留原生圆角。自绘及原生组件缺失的着色回退现也使用同一原生圆角矩形。这是指定样本静态边界，动画、文件夹、最近任务、编辑、深色和动态壁纸仍待实机验收。

主要实现为 `LauncherDockBackground`、`DockBackgroundGeometry`、`DockGlassBackdrop` 与 `DockOptics`，位于 [`mods`](../../../app/src/main/java/tv/withaibuild/customiuizer/mods/)；布局、材质、采样及 Launcher Hook 的职责分别保留。公共模糊开关与其他窗口共享，不能作为 Dock 私有状态搬入功能包。功能行为、样本推断与实机测量分别记录。
