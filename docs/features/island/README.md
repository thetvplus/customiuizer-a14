# 动态岛

[功能目录](../README.md) · [音乐手势与操作](MUSIC_GESTURES.md)

适用于 HyperOS 1 / Android 14 / libxposed API 102。入口：**系统 → 动态岛**。首次选择动态岛模式后需重启系统界面，安装其业务接入；应用反馈、媒体与通知接管默认关闭，开启相关接入后也需重启。系统反馈逐类选择，新安装默认关闭；升级已启用动态岛且没有新分类配置的旧用户保留原十类反馈。分类监听、已安装接入的尺寸、动画和手势配置即时更新。普通 Toast 的位置、时间和过滤仍在「系统 → Toast」。

## 两种形态与交互

| 形态 | 内容 | 尺寸 |
| --- | --- | --- |
| SHORT / 短岛 | 音乐封面 / 波形、头像、简短系统状态 | 自动首选 184 dp；手动 160–224 dp |
| LONG / 长岛 | 需要较多文字的应用、通知或可安全适配的原生反馈 | 自动按内容最多 240 dp；手动 184–280 dp，且不窄于短岛 |

自动宽度随高度温和联动，字号与图标分别适配；手动宽度保留原范围。两者共用 38–44 dp 的高度（默认 40 dp）及完整胶囊端帽。长度主要改变中段；摄像头和物理安全 Insets 优先。居中模式保留原生时钟 / 电量留白，中间留白至少为 40 dp，或实际挖孔宽度加 16 dp，两者取大。左右模式使用连续内容区，不保留固定中央空隙，也不按时钟 / 电量占用限制宽度；必要时由实际相交避让暂时隐藏图标。没有独立的大卡片、详情面板或媒体按钮。

单击打开播放器 / 对应应用；通知使用匹配原条目的原生行点击。音乐提供左滑、右滑、下滑、双击、长按五项配置，默认左滑下一曲、右滑上一曲，其余无操作。左右切歌开关默认开启，关闭只阻止横向切歌，其他明确映射仍可用。上滑固定收起当前活动；通知和系统反馈保持既有交互。未配置双击时单击无额外等待；多指、CANCEL、失效、配置及内容变更取消候选。详细动作、能力与取消合同见[音乐手势](MUSIC_GESTURES.md)。

旧展开宽度及已移除的图标、状态精简、手势 / 媒体控制偏好不再参与运行时读取。设置进程启动时精确删除这些旧项（包含短键 / 存储键），不清空其他设置；备份导入和导出也排除它。新的切歌开关使用独立的 `system_island_media_swipe`，默认开启，不复用旧手势键；跟随当前 XML 进入偏好目录与备份。无需通过全局偏好契约版本升级清理其他数据。

横向位置可选左 / 中 / 右及 ±80 dp 偏移，默认居中零偏移。左 / 右分别锚定实际安全区域左 / 右边界，偏移相对于该边界施加；缩宽时保持选定边不动。物理挖孔相交时只在同侧缩宽，内容无法适配则向挖孔下方避让，不回到中央或跳到另一侧。居中模式继续与摄像头融合。中心扩展动画分别从选定边或摄像头展开 / 收回。横屏保持原有安全隐藏策略，转回竖屏重新读取 Insets 与开孔。状态栏仍依据真实动画边界逐项避让。

设置入口位于“系统”的“系统界面”组，紧跟“状态栏”，与通知中心、控制中心同级。页面依次分为基础设置、位置与尺寸、外观与动画、反馈与通知、音乐与交互五组。十类系统反馈进入独立子页；五项音乐手势在音乐与交互下进入独立子页。应用通知允许名单、保留原生悬浮与应用排除相邻，后两者优先于允许名单。动画样式名为“上下”和“中心”，存储编码不变。

## 展示与状态栏

只保留 `IslandActivityController` 的一个模块窗口与 `IslandActivityView`：音乐、短时反馈、通知和十类系统终态全部共用它，不再借用原生 StrongToast 窗口。已删除原生布局适配、图标改写、独立动画及原生抢占 / 去重依存。展示门控为 `IDLE → PREPARED → VISIBLE → EXITING → IDLE`，身份令牌代表一次事件，generation 保护退场回调。

PREPARED 只准备内容，不取得状态栏占用。有效布局、真实 attach、窗口可见、非透明内容、有效绘制区域，以及原生安全状态均成立后，才转为 VISIBLE 并取得占用。`parent != null` 不构成可见证明。锁屏、息屏、控制中心遮挡、布局失败、取消或解绑成对释放；旧窗口 / 旧动画不能恢复新事件下面的状态栏或移除新窗口。

短岛和长岛按实际动画矩阵与窗口偏移计算屏幕边界，只临时隐藏与岛相交的单个图标；未相交图标、分组和排序保持原样。时间、电量容器及其中的 Duo 仅在确实相交时避让。不识别的 ROM 布局不再回退为整条状态栏淡出。叶图标记录在布局更新时精确恢复 / 剔除失效项，最多保留 128 个当前项。隐藏约 320 ms、恢复约 400 ms；硬件绘制且模块允许模糊时，使用有界临时图像和 RenderEffect。已有原生 RenderEffect 不被覆盖，失效或解绑即释放；不支持则退回 alpha，简化或系统动画关闭时直接完成。

勿扰、铃声模式、深浅色、飞行、NFC、热点、手电、Wi-Fi、移动数据和蓝牙均可逐类选择，只有选中类别才建立对应监听，关闭后释放并删除待显示事件。全部反馈来自真实终态。初始、重复与过渡态不报成功。一个最新待显示槽固定收集 200 ms；控制中心展开时不在其上绘制、不改变状态栏。收起后只显示仍有效的最新项，从原事件起最多 6000 ms，实际展示不超过剩余期限与常规停留时长。超过期限、锁屏、切用户或所有者销毁即丢弃，不无限重播。

350 ms 内勿扰引发的响铃变化、飞行模式引发的无线关闭只保留主反馈；原生 AudioManager 指令和磁贴仍用于识别独立操作，解除对应因果合并。所有状态统一来自原有系统终态监听，不再把插件的第二份原生提示作为另一种显示或去重来源。

## 原生额头与充电边界

动态岛开启时，在 StrongToastControl 的统一显示入口直接结束该次显示请求，不创建原生额头窗口或动画队列。因此系统反馈只走模块窗口，没有原生额头回退、透明原生窗、原生图标改写或触摸区域适配。未知 StrongToast 内容不伪造成功反馈，也不能把额头带回来。

独立的 `MiuiChargeController` / `MiuiChargeAnimationView` 继续由系统管理，没有新增 Hook 或电池监听。StrongToast 的大型充电视频不再挤进胶囊，也不以额头回退显示；本版未新增自绘充电岛。系统默认和匹配状态栏高度两种模式的原生行为继续保留。

## 音乐、应用反馈与通知

音乐只使用系统已选中的主播放器，进入其来源应用时隐藏，离开后按当前真实状态恢复。播放先等 750 ms；只有已经实际预绘制显示的本次音乐活动才有暂停后约 2 秒的退场保留期，metadata 更新不续期。未显示的窗口直接移除，避免退出动画制造闪现；被遮挡的新播放不能沿用旧会话历史展示记录建立暂停岛。在音乐应用内暂停、入场延迟内暂停或由其他提示占用窗口时，不新建暂停音乐岛；快速回桌面和重复暂停快照也不使它闪现。暂停保留期间进入播放器会消费剩余保留期，返回桌面不再重开；真实恢复播放仍按正常入场延迟显示。上滑隐藏绑定同一会话，换曲 / 旧快照不撤销隐藏，真实暂停 / 恢复边沿才重新激活。回调绑定会话及当前控制器，停止、隐私遮挡、替换和销毁时释放；控制中心临时遮挡保留原期限和真实边沿。

“音乐直接上岛”默认关闭，应用选择默认空；在音乐与交互中开启并手动选择应用后，播放时上滑退出所选播放器，桌面的原生窗口动画以岛为终点，岛接着轻微回弹。首次启用需重启桌面。仅支持当前用户、竖屏、单个标准全屏任务的 CLOSE_TO_HOME；任务、应用和播放会话身份必须一致。最近任务、快速切换、分屏、小窗、横屏、未选中应用、空名单和不可确认的状态均保持原生路径。

只有桌面实际采用新终点、原调用成功且原生窗口动画正在运行，SystemUI 才接受一次确认，在 80 ms 会话复核后使用 560 ms 的有限接入动画；没有桌面确认时保留原 750 ms 音乐入场策略。每次只保留一个按 token 绑定、750 ms 失效的候选，重复 metadata 不重播。关闭开关 / 撤销选择、二次切换应用、暂停、换会话、隐私状态、通知抢占和 owner 失效均撤销；未入场的候选撤销时恢复原截止时间。简化动画或系统动画关闭时跳过这项动效。

普通 Toast 只接入完整、无格式、单行且能完整放下的文字；明确的成功 / 保存路径可精简，其余保持原文。长文、自定义、空间不足、副屏、来源缺失安全条件或挂窗失败时使用原生反馈。封面、头像、图标及明确成功状态精简均为固定行为，不再设开关。十类系统反馈仅按固定名称白名单加载当前 ROM 原生图标。勿扰和静音优先读取挂载的 miui.systemui.plugin 四个原生提示资源；不加载插件代码，不持有控制器或 Context。其余模式或缺少提示资源时读取 SystemUI 原生快捷开关图标（含主题覆盖），再缺失使用 Android 原生信息图标，不手绘替代。每个事件独占 Drawable，统一白色对比。冷路径以至多 96×96 的临时画布测量透明留白，立即释放；仍委托 ROM Drawable 绘制，将实际可见图形归一到 24 dp 单元中的约 20 dp，保留纵横比，不复制或重画图标；测量失败保留原生素材，单元继续限制其边界。相机留白与两侧图标空间完整可用后才出现，不抢占全局图标或其他应用。波形提供关闭、轻量动画和实时波形三种模式，默认轻量动画。当前模式与实验 / 回退说明分别展示，回退条件不会被当前值摘要隐藏。轻量模式只表示播放状态；实时模式明确标记实验性，使用共享 FFT 数学将实际音频数据映射为五柱，有界平滑并限制至最多 20 Hz。只有可见且播放、非简化动画、目标 UID 属于当前用户、唯一媒体会话与唯一活动媒体音轨可确认时才允许采集；匿名 UID、多个候选、远程路由、权限 / AppOps / Visualizer 不可用、格式无效或首帧超时均回退轻量动画，不使用全局混音 session 0。原始 FFT 不保留、不记录、不上传；隐藏、暂停、息屏、换会话或关闭立即作废回调，并在同一资源锁中释放监听和原生对象。没有新增 APK 录音权限或录音服务。

通知接管默认关闭，应用允许名单默认空，只有选中且不在排除 / 保留原生名单中的应用才接管；其余正常走原生通知。只在原生已通过分组、排序、提醒规则并完成悬浮绑定的阶段接入标准消息及有真实封面的图片通知。保留通知中心原件；失败、静默、免打扰、前台、排除、敏感、应用锁、自定义、全屏、汇总、常驻及其他用户内容继续走原生路径。按应用保留悬浮仅影响通知接管。精确 key / 版本识别，重复绑定不延长 4 秒期限；使用内存中公开内容与已加载图标，不读取 URI 或应用数据库。点击交给原生行，不另发 PendingIntent、不直接删除通知，原生 unbind 与弱引用释放维持闭环。

## 动画与资源

模块窗口只有一个有限 ValueAnimator 时钟，五个标量通道描述物理宽、高、位移和透明度。解析临界阻尼模型以物理像素保留当前位置 / 速度，目标改变不重置速度；常规进入 360 ms、变长 / 收缩 320 ms、取消回位 280 ms、退出 300 ms；音乐与第二活动的交接放缓为 440 ms，内容层稍后渐入。“中心”只改变横向宽度和透明度，高度与纵向位置全程固定；不加上下回弹。“上下”保持完整宽高，从顶部进入并向顶部退出，不再共用中心收窄退场；中断 / 重入沿用同一有限时钟和旧回调失效机制。摄像头下限和安全宽度约束优先，终点没有胶囊 / 面板算法切换。图标、文字、波形反向补偿非等比形变，维持物理比例和 16 dp 边距；新文字等有足够空间后在同一时钟中出现。

进入可选上下滑动或中心扩展。中心扩展从首个可见帧即保持最终胶囊高度，以同高小圆胶囊为起点横向伸展；退出反向横向收窄至同高圆胶囊并淡出，保持纵向位置，不同时放大或压缩宽高。所有活动直接使用同一个模块窗口、视图与动效实现。简化模式和系统动画关闭时直接设置正确终态。没有新线程、轮询、无界缓存或动画库。Surface 四边保留 80 dp 对称有界绘制外扩。原有单窗口增加输入容器，按 IslandRecallHit 设置 12–16 dp 有界触摸外扩，并将实际动画区域写入 WindowManager 的 touchableRegion；状态栏占用继续只读取内部胶囊的真实边界。没有第二个窗口或整条状态栏触摸层。短上滑根据高度和 touch slop 判定；快速上滑可缩短阈值，释放时用完整位移补判缺失的 MOVE，同时保留锁轴、多指 / CANCEL 和单次提交。

已制作真实 View / Path 的 60 / 120 Hz 主机采样、完整进出及反转关键帧，检查位置 / 速度连续、端帽和内容比例；这不是设备 FPS 测量。不再有原生胶囊动画路径或退场连接层。

窗口飞入复用 HyperOS 1 桌面的 WindowElement / RectFSpringAnim，只在提交返回时复制 RectFParams，修改终点、终点圆角和原生浮动图标交接；窗口表面、当前速度、进度更新、结束与取消回调继续由桌面持有。原参数不变，原调用恰好执行一次，不另造窗口截图或浮动封面层。岛附近的接入沿用现有单窗口、有限时钟、准备好的封面和输入边界；时长与弹幅为本项目候选值。

SystemUI 与桌面通过显式、校验 Android 14 发送者身份的消息交换选中包名、用户、几何和短期时间戳，不传标题、封面或音频。桌面只在手势按下时异步刷新，最多缓存一份 5 秒有效状态；提交成功后异步确认一次。业务 Receiver / Scope 随开关、NavStubView 与岛 controller 的所有权注册和释放，关闭时没有业务接收器或任务。没有 MOVE / 逐帧 IPC、轮询、额外 Bitmap 或动画依赖。

本次结合 [Apple Live Activities HIG](https://developer.apple.com/design/human-interface-guidelines/live-activities) 的信息精简、图形比例、布局连续性、避免元素碰撞、短时过渡与相关内容直达原则：保持既有短 / 长岛布局、封面正方形和物理边距；窗口交接后封面渐入，不堆叠文字和额外按钮；单击仍回到对应播放器。隐私、减少动画、Android 14 的宿主生命周期与项目安全门禁优先；没有引入 ActivityKit 或额外动画依赖。

设计研究：[Live Activities HIG](https://developer.apple.com/design/human-interface-guidelines/live-activities)、[WWDC23 Dynamic Live Activities 7:37–14:16](https://developer.apple.com/videos/play/wwdc2023/10194/)、[Animate with springs](https://developer.apple.com/videos/play/wwdc2023/10158/) 与 [Android Spring Animation](https://developer.android.com/develop/ui/views/animations/spring-animation)。开源参考 [dynamic-island-android](https://github.com/Arnav-Dugad/dynamic-island-android) 的运动 / 状态 / 轮廓思路；该仓库没有独立授权文件可确认代码复用，本版未复制其源码、素材或参数，也没有引入 Compose。这里的时间与参数是本模块的候选值，不是 iOS 官方数值。

验证、变更统计、独立审查及回退单位见 [A14 精修路线图](../../maintenance/A14_REFINEMENT_ROADMAP.md)。本页描述当前工作分支源码；本次专项精修没有预设版本号或发布 Release，主机、ROM、APK 与设备证据分别记录。

## 实现与验证入口

实现集中在 [`mods/island`](../../../app/src/main/java/tv/withaibuild/customiuizer/mods/island/)，对应测试在 [`mods/island`](../../../app/src/test/java/tv/withaibuild/customiuizer/mods/island/)。`DynamicIslandActivities` 负责 ROM 接入，`IslandActivityController` 负责所有权和会话，View / Motion / Sizing 负责呈现，通知及系统活动各有明确入口。通用 Hook、安全边界、偏好与 StrongToast 快照继续由共享基础设施持有。

## 设置与备份兼容

页面迁移保持所有现有设置与音乐 payload 的键和值。新增 `system_island_waveform_mode`：`0` 关闭、`1` 轻量、`2` 实时；旧 `system_island_waveform=false/true` 仅在新键不存在时分别映射为 `0/1`，旧键原值保留并仍可备份。显式新模式优先，值以字符串保存；数字导入先规范类型，新装默认 `1`，未知新模式安全回退轻量。旧备份在原子提交之前补迁移，无需等待应用进程重启；旧动态岛模式 `3/4` 都保留原反馈，部分新格式不补开遗漏分类。搜索索引使用两个真实子页与 System 控制器，保持面包屑、动作编辑、摘要和依赖。首次安装业务接入需重启系统界面，已安装接入中的模式、尺寸和动作即时更新。
