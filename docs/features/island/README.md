# 动态岛

[页面功能地图](../../FEATURE_MAP.md) · [音乐手势与操作](MUSIC_GESTURES.md) · [待验收与证据](../../maintenance/A14_REFINEMENT_ROADMAP.md)

本页描述当前源码，后续分支能力不等于同版本正式 APK 已包含。适用平台见根兼容矩阵。

## 设置与兼容

入口为系统 → 系统提示，顶部统一选择提示样式。首次选动态岛模式及开启 Toast 反馈、媒体 / 通知接入后须重启 SystemUI；这些接入默认关闭。系统反馈逐类选择，新安装默认关闭；已启用动态岛且没有分类配置的旧用户保留原十类。已安装接入的分类、尺寸、动画与手势即时更新。普通 Toast 的位置、时间和过滤仍在系统 → Toast。

主页面按内容、外观、交互组织：内容集中媒体、消息通知、系统活动及应用排除；外观进入位置尺寸、波形与动效；交互包含常驻小岛与手势。媒体页管理媒体接入、滑动切歌和小窗媒体排除；公共波形供媒体与录音共用，不依赖媒体开关。自定义动作及媒体 / 持续活动的确认 Home 回岛集中在手势页；上岛效果使用共用动效配置。持续活动使用原生静态多选菜单，不在进入页面后重建开关。短信、日历不再单列，统一由消息通知的接入应用决定；旧分类值在设置启动和备份导入时移除，运行时也不会绕过应用名单。位置尺寸按位置、高度、宽度分组，自动尺寸隐藏手动滑块。消息接入名单与保留原生横幅相邻，排除优先。名称、说明和右侧值同属一个功能，说明不单独用分隔线拆开；原生 Preference 依赖继续管理启用状态。

页面迁移保持有效键、动作整数和 payload。旧展开宽度及已退役图标 / 状态 / 手势 / 控制键不再读取，设置启动时精确清理其短键 / 存储键，导入导出过滤，不清其他数据。新切歌开关 `system_island_media_swipe` 默认开启，不复用旧键。

`system_island_waveform_mode` 以字符串保存：0 关闭、1 轻量（默认）、2 实时。新键不存在时旧 waveform=false / true 映射 0 / 1，旧键仍可备份；显式新值优先，数字导入先规范类型，未知值回退轻量。旧备份在原子提交前迁移；旧模式 3 / 4 保留原反馈，部分新格式不补开遗漏分类。搜索使用真实子页及 System 控制器，保留摘要、依赖、面包屑和动作编辑。

## 形态、位置与输入

| 形态 | 内容 | 宽度 |
| --- | --- | --- |
| IDLE / 小岛 | 可选静止胶囊，下滑打开通知栏，点击无动作 | 自动以 100 dp 为基准，联动岛高与挖孔；或手动 48–120 dp，始终不宽于短岛 |
| SHORT / 短岛 | 媒体封面 / 波形、头像、简短反馈 | 媒体在 40 dp 高度下自动首选 160 dp；短反馈按实际字形与摄像头通道收窄；手动 96–320 dp |
| LONG / 长岛 | 系统持续活动速览、消息正文及较多文字 | 40 dp 高度下自动至少 184 dp、最多 320 dp；手动 120–400 dp，且比短岛至少宽 24 dp |

展开后的长岛按实际标题 / 详情、图标及间距测量自动宽度：40 dp 高时从 184 dp 起按需增长，且目标至少比当前短岛宽 24 dp，最高 320 dp；短岛为长岛保留 24 dp 可用空间，物理边界优先。居中形态两侧至少各留 24 dp，并服从系统上部圆角的内侧安全边界；手动长宽继续按用户配置并接受同一物理限幅。弹性承接最多借用 8 dp 空间，受两侧实际余量限制。

三种形态共用高度与同一个窗口；自动高度使用系统挖孔的竖向尺寸，优先匹配 36–40 dp，受实际状态栏高度约束后为 32–40 dp，无挖孔时以 38 dp 为基准。手动仍为 32–64 dp，完整胶囊端帽。长度只改变中段。非默认的既有手动高度在自动键缺失时保留，明确选择的手动 40 dp 不重新推断为自动；自动模式也不把测得的尺寸写回手动值。自动宽度随高度温和联动，文字、图标、封面、波形与触摸几何同步适配。没有独立大卡片、详情面板或媒体按钮。长岛将封面 / 头像与曲名 / 发送者放在左侧，独立歌手 / 正文放在右侧并靠右对齐，两侧分别在挖孔外截断；音乐主次字号区分，通知正文在高度足够时使用两行。计时内容仍由原生 Chronometer 持有，详情可分行；重复补充内容隐藏。短岛音乐继续使用封面与波形，不重复显示曲名。同一内容的几何查询、前台切换及底部手势条回桌面不重设字体；仅真实内容、形态或配置变化更新布局。纯文字应用反馈可在长岛使用两行，入场前按实际字号、宽度与高度验证完整文本，放不下则保留原生 Toast。

位置左 / 中 / 右，默认居中零偏移。横向滑块在 ±80 dp 上限内按三形态最小宽度、封面位置和挖孔连续限幅；靠左只提供向右调整，靠右只提供向左调整。左 / 右锚定安全边界，缩宽不移动选定边；遇挖孔只同侧缩宽，放不下时移至其下，不跳到另一侧。自动居中保持时钟 / 电量留白及至少 max(40 dp, 挖孔宽+16 dp) 的中间空隙；手动宽模式和长岛允许时间、电量避让或隐藏，仍保留挖孔和物理安全边界。左右使用连续内容区，不受固定中间空隙或时钟 / 电量占宽限制。横屏沿用安全隐藏，回竖屏重读 Insets。

来源区分小岛、媒体、通知、系统活动和即时反馈，共享同一窗口与协调器。媒体默认短岛；持续活动默认长岛，按实际标题、详情与时钟测量。活动单击打开当前来源应用 / 播放器，通知交给匹配 Row 的原生点击。有独立正文的消息直接长岛，不按中英文字数设门槛；自动尺寸按内容测量，手动尺寸使用已设长岛宽度。只有标题、空正文或正文与标题重复的通知保持短岛。目标为长岛时直接进入目标，已有实例从当前物理几何连续变化。同一身份的普通更新不重播入场，也不撤销主动关闭；通知和一次性反馈按来源生命周期结束。

所有来源一次上滑退出当前来源；下滑不展开。媒体默认短岛，下滑使用已存动作；系统持续活动默认长岛，以同一窗口按内容测量并受最大宽度限制。常驻小岛手势独立。消息通知优先于即时系统反馈、普通 Toast、持续活动和音乐：消息可接替低优先级瞬时反馈，展示期间新的反馈不能覆盖它；原生通知重要性、隐私和免打扰门禁继续生效，不新增通知队列。来源退出或自然结束后回到仍有效的系统活动，再到媒体；没有活动时回常驻小岛或退场。系统活动的主动退出按其身份抑制到来源结束；重复更新不会撤销同一活动的主动退出。顶部退场保持释放时的物理宽高，居中退场沿原胶囊收束。音乐动作、取消及会话门禁见[音乐手势](MUSIC_GESTURES.md#输入会话与生命周期)。

一个固定宽度的透明状态栏画布容纳同一岛体，几何变化只更新岛体位置 / 形变，关闭原生窗口移动动画；Surface 使用对称 16 dp 外扩。同一窗口输入容器仅将岛体的动画区域和 12–16 dp 有界外扩写入 touchableRegion。没有第二个窗口或整条状态栏热区。上滑意图在点击分发前按原始坐标锁定，短于收起阈值也只回弹；快速释放补判缺失 MOVE，保留锁轴、多指取消和一次提交。窗口外通知栏 / 控制中心手势交原生。

上滑量程在 DOWN 按岛体实际高度冻结，包含自动高度：意图约为高度的 7%，提交约为 16%，再由本岛 touch slop 和小范围物理下限约束。点击取消使用更小的本地上滑位移门槛，斜向短滑也先否决点击；意图与提交仍单独判定，不足提交距离只回弹。历史采样中的上滑后回落同样保留否决，不能因 UP 接近起点而打开应用。短促快划使用同一高度导出的速度门槛，UP 可补判合并的 MOVE。只调整本岛判定，不改变全局导航 / 通知栏手势或系统共享 touch slop。

## 展示与状态栏

`IslandActivityController` / View 共用一个模块窗口和身份租约：IDLE→PREPARED→VISIBLE→EXITING→IDLE。PREPARED 不占状态栏；有效布局、真实 attach、可见窗口、非透明内容、绘制区域及原生安全状态齐备后才取得占用，parent 非空不足以证明可见。通知中心展开时，活动沿同一时钟收为静止小岛，暂停波形和媒体采集并关闭热区，原生下拉不被截获；通知中心收起后复核当前会话再恢复。锁屏、息屏、其他遮挡、布局失败、取消 / 解绑成对释放，generation 拒绝旧退场移除新窗口。

按真实动画矩阵与屏幕偏移判定相交叶图标，小图标判定边界额外外扩 4 dp，黑岛实际边界保持；未相交图标、分组、顺序保持。时间、电量和 Duo 仅相交时避让；未知布局不退回整条淡出。至多记录 128 个当前叶项，布局时恢复 / 剔除离树项。隐藏约 320 ms，恢复约 400 ms；允许模糊且硬件绘制时使用有界临时图像 / RenderEffect，不覆盖既有 effect，失效释放；不支持回 alpha，简化 / 系统动画关闭直接完成。

小窗来源排除默认关闭，首次开启须完整重启设备；安装状态跨偏好刷新和 controller 替换保持。开启后按当前用户 / 默认屏幕的原生 PiP 组件、至多 16 项 freeform 包名及应用悬浮窗 UID 反选媒体来源。只有可确认属于小窗的媒体被排除，独立音乐、已允许的通知、普通提示、系统反馈和小岛继续按原有规则显示。未知来源不扩大为全局隐藏；原生 PiP / Home 事务仍保护对应视频的返回动画。系统来源广播仅传有界身份和时序，不传标题、音频或窗口对象；绘制前只读已发布的标量快照，无逐帧查询。

## 来源规则与复用

| 判断 | 共同入口与策略 |
| --- | --- |
| 通知准入 | IslandOptions 只按启用状态和显式应用允许名单正选；全局排除 / 保留原生优先。空名单不扩为所有应用，旧短信 / 日历分类不绕过名单 |
| 原生窗口返回 | 同一设置快照生成允许且未排除的媒体 / 系统活动包集合；Launcher、发布、提交确认和入场共用该规则。媒体与活动开关分别生效 |
| 小窗来源排除 | 只对明确归属的当前媒体反选；PiP 的包、用户及默认屏幕身份共用标量判断。窗口交接另保留可见 / 收边语义，不把两种用途强并为同一状态条件 |

IslandOptions 在偏好读取时复制应用集合，异步操作持有的旧快照不会随原集合原地改变；可返回媒体名单在快照生成时筛选，事件处理只查询已有集合。派生集合容量不超过配置名单，不按事件增长；替换后随旧快照及相关任务结束释放，不保存配置历史。IslandLiveKind 统一声明原生状态生产者及可返回窗口包，作用域、源进程、订阅、广播归属与窗口选择复用相同元数据，设置路径不反向依赖广播实现。原生通知排序、隐私、发送者、用户和任务等安全校验仍在各自提交边界重验。

媒体被排除或等待原生 PiP 准备时，仅过滤媒体槽；没有可展示媒体后，其他活动或小岛继续使用原窗口和同一有限动画时钟。小窗媒体不能关闭独立录音等活动的返回发布器；仅剩被排除媒体时仍释放其发布器。媒体与原生活动都在实际前台变化时更新返回快照，不加轮询或延长旧快照寿命。原生媒体返回失效只取消自身接入进度，其他来源的内容交接继续由共享时钟完成；手势、退场和解绑保留整体清理。

正选 / 反选按目标使用，不枚举全部安装应用构造补集。持续活动沿用至多八槽的 EnumMap，仅遍历已存在活动确定优先级，不增加队列、堆排序或消息历史。这里只说明状态量与执行路径，不据此宣称设备 CPU、内存或续航改善。

## 系统与应用反馈

十类为勿扰、铃声、深浅色、飞行、NFC、热点、手电、Wi-Fi、移动数据、蓝牙；仅选中类别注册监听，关闭释放并丢弃对应待显示项。只报告真实终态，不把初始 / 重复 / 过渡态写作成功。单个最新槽收集 200 ms；控制中心展开时不绘制或占状态栏，收起仅显示仍有效最新项。事件总寿命 6000 ms，展示不超过剩余期限；锁屏、切用户、超时、owner 销毁即丢弃。

350 ms 内由勿扰引发的铃声变化、飞行引发的无线关闭仅留主反馈；原生 AudioManager 指令 / 磁贴仍识别独立操作并解除因果合并。不再拿插件第二份提示作另一来源。

动态岛模式在 StrongToastControl 统一显示入口结束请求，不创建原生额头窗口 / 动画队列，不保留透明窗、原生图标改写或未知内容回退。独立 MiuiChargeController / MiuiChargeAnimationView 仍由系统管理，锁屏大充电动画保留。充电和低电量分别选择，默认关闭；启用后只监听电池终态边沿，初始 / 重复快照不提示。低电量采用 20% / 10% / 5% 阶段；只有替代岛可见后，才发布最长四秒的临时确认，让安全中心沿既有设置读取抑制底部弹窗。未显示、迟到 / 失败写入、隐藏 / 释放均保留或恢复 native；不持久改变系统低电量选项。首次启用低电量接管须重启系统界面和安全中心。系统默认与匹配高度模式继续保留原生行为。

普通 Toast 仅接完整、无格式、单行且能放下的文字；明确成功 / 保存路径可精简，其余原文。长文、自定义、空间不足、副屏、安全来源缺失或挂窗失败保留原生反馈。

封面、头像、图标和明确成功状态精简为固定行为。十类图标按固定名称白名单读取 ROM；勿扰 / 静音优先挂载插件四个提示资源，其余用 SystemUI 原生开关含主题覆盖，再缺失用 Android 信息图标。不加载插件代码或持有其 controller / Context。事件独占 Drawable，白色对比；冷路径至多 96×96 临时画布测透明留白，立即释放，归一到 24 dp 单元中约 20 dp 可见图形且保持比例。失败保留素材，不手绘 / 重画；空间完整后才显示。

## 音乐与原生返回

正常跟随系统选中的主播放器；小窗来源反选命中后，至多保留一个曾由系统选中过的独立播放器作为候选，不保留其封面、不增注册回调；每次使用前重新核实当前用户、真实 PLAYING（已显示的同一会话加载中可静置保留）和排除规则，主动收起、失去 native owner、安全失效或销毁即清除。进来源 App 隐藏，离开复核真实状态，普通播放入场等 750 ms。在途首份读取也受前台变化 / generation 失效，native owner 丢失清媒体；闹钟等临时移走原生卡片但操作系统仍确认相同 token / 包名时，真实 PLAYING 继续使用现有会话回调，PAUSED 按原两秒期限隐藏并仅保留回调最多 30 秒等待恢复。重复快照不续期，未恢复即释放；旧 PLAYING 不能复活，也不新增轮询。

明确 BUFFERING / CONNECTING / SKIPPING 时保留现有封面和标题，波形停钟、释放采集；实际 PLAYING 后只交接一次最新曲目。不对明确仍加载的有效会话使用普通暂停超时，也不轮询。加载后仅收到 PAUSED 的含糊中断最多等待 30 秒，重复快照不续期；首次只有加载状态不新建音乐岛。STOPPED / ERROR、会话销毁、来源或安全失效仍立即清理。

暂停保留、预绘制证据与会话释放统一见[音乐手势的暂停可见性合同](MUSIC_GESTURES.md#暂停可见性)。上滑 dismissal 绑定同 session，换曲 / 旧快照不撤销，真实暂停 / 恢复边沿才激活；控制中心暂挡不重置期限。

音乐直接上岛默认关闭、名单空，启用并选择 App 后须首次重启 Launcher。只接受当前用户、竖屏、单一标准全屏任务 CLOSE_TO_HOME，包 / 任务 / session 一致；最近任务、快速切换、分屏 / 小窗、横屏、非名单或未知保持原生。

复用 Launcher WindowElement / RectFSpringAnim。上滑确认与经典导航 Home 共用 CLOSE_TO_HOME 的原生采纳检查；经典 Home 从 WindowAnimParamsProvider 的实际 A14 关闭任务读取用户、任务、显示器、全屏和自动 PiP 元数据，不另查任务。最近任务、按住未提交和其他任务不出岛。两种效果均在原生查找桌面图标前选择无图标目标，并复制 RectFParams 改窗口终点、圆角和图标标志；不借用或再次飞回已经在桌面的图标。默认沿原生窗口轨迹衔接岛体，吸入额外将页面收进窄口。起点矩形与松手 alpha 保留；非透明任务的结束 alpha 固定为松手值，真正透明任务保持原生透明度合同并不捕获网格。原生速度、阻尼、回调与任务归属保持。

仅 native 实际采用本次参数、原调用成功且动画运行才确认，SystemUI 复核当前来源后立即接入。已选择返回的应用等待确认；普通未选择媒体保留既有 750 ms 展示等待。每次确认只消费一次，重复快照不重播。关开关 / 撤名单、二次切 App、暂停 / 换会话、隐私、通知抢占、owner 失效撤销。简化或系统动画关闭直接设终态。

真实 Home 边沿对离开的应用做一次至多 16 项的任务查询，声明自动 PiP 的候选等待对应原生任务稳定或取消后才应用展示策略。每个 controller 只保留一个意图、串行查询和 2.5 秒兜底；独立 Shell 入场请求绑定单个 token，原生状态、取消、owner 替换或五秒截止清除。普通音乐查询无候选即放行，不统一增加动画延迟。

显式消息核验 Android 14 发送者，仅传选中包 / 用户 / 几何 / 短期时间戳及有界进度令牌，不传标题 / 封面 / 音频。Launcher 在 DOWN、原生打开和来源前台边沿异步刷新；准备快照由可撤回的 SystemUI Binder owner 持有，owner 死亡或新状态即失效，长时间按住不会仅因五秒过期丢失 Home 返回。成功原生提交异步确认一次。两种效果每次只在 IO 交换一次只读 SharedMemory 标量，默认不捕获页面；动画帧在两个进程本地原子读写，Java 用直接 VarHandle 标量调用。结束 / 取消 / owner 释放关闭映射及句柄；自然完成不再恢复已经隐藏的结束窗口，取消只恢复仍归本次参数的窗口。Receiver / scope 随开关和窗口 owner 释放；没有每帧 IPC 或常驻轮询。

实时波形默认关闭，默认轻量只表示播放。共享 FFT 映射五柱，采样遵循 ROM 上限（当前实机为 20 Hz），攻击 / 释放按实际时间平滑并过滤细微变化和量化噪声；显示层按约 30 Hz 插值，仅五柱变化期间刷新，静音 / 稳定后停止时钟，不修改屏幕全局刷新率。仅可见播放、当前目标布局需要波形、非简化 / 非省电、当前用户的本地选中播放器 UID 可采集，拒绝远程、通话、全局 session 0 和跨应用 / 用户音轨。展开媒体长岛只显示文字时，释放采集和音轨监听；短暂交接只保留已有五柱帧，不继续采集，回到需要波形的短岛后重新取得一次租约。按目标内容判定，不等待旧子 View 淡出结束。HyperOS 可为 Telegram 复制媒体会话；选中 token、包、UID / 用户须相符，会话数量不再当作音轨数量。同应用多媒体音轨优先固定当前 session，停播后才按稳定顺序重选，其他应用的音轨不会参与。更换同应用会话时短暂保留最后一帧，首帧失败 / 超时回轻量，不循环重试。FFT 不保留 / 记录 / 上传，隐藏、暂停、息屏、换用户或关闭即失效并释放；不新增 / 申请录音权限，仅复用 SystemUI 既有权限。SystemUI 原生权限 / AppOps / Visualizer 不可用时仍回退。

媒体实时柱使用 Visualizer 的 `SCALING_MODE_NORMALIZED`，在原生量化之前保留低音量下的可视化信号；它表示内容的频率起伏，不按系统音量显示客观响度。设置返回值及模式读回均须匹配，否则释放本次采集并保持静止。该路径拿到的是原生已转换的 8 位复数 FFT，与录音原始峰值合同不同；MP3 / AAC / M4A / WAV / FLAC / Opus 等源的编码码率和解码位深不参与柱高换算，也不从扩展名猜测音质。高位深源经系统混音后的实际采集率才参与频率映射，无法借可视化证明源文件质量。

每次取得采集租约时，按原生采集率和容量选择 512 或 1024 点：超过 102.4 kHz 请求 1024 点，确保原生容量允许时第一段 200 Hz 内仍有可观测频点；结果继续限制在原生范围，不能补造超出容量的低频。这里只在安装采集时多读一次采集率并核验设置，不增加逐帧系统查询、解码器、文件读取或额外采集任务。映射逐帧使用回调报告的实际采集率，保留固定高频显示补偿和当前攻击 / 释放；换轨第一帧静音会清除旧曲目柱高，过期回调不能恢复。无回调 / 不支持 / offload 或受保护播放不可用时保持既有回退，不绕过原生保护。原生容量内的格式无关 Host 回归与实际播放器 / 耳机 / 音频路由验收分别记录。

实时档新增公共波形显示增益 `system_island_waveform_gain`：100–800%，步进 25%，默认 200%。仅放大已测得的五柱标量，音乐与录音共用，不改变媒体音量、麦克风录制增益、采样开关或权限。静音保持平直；不可用的实时后端保持静止。只保留五个归一化标量供即时重算，隐藏 / 换源按已有租约清理。

上岛效果可选择「默认」或「吸入」。默认直接显示岛，不创建捕获画面或上岛 Animator。吸入复用原生窗口进度及硬件 Canvas 网格，上缘在前 14% 接入窄口，后缘保留体积再压缩；窄口位于实际岛体水平中央、从顶部起高度的 90%。岛的实际外弹宽度在网格后缘已走完约 90% 的物理行程时达到峰值，随后沿同一有限时钟阻尼回弹，页面完成不再截断回弹。页面主体保留松手 alpha，仅接近窄口的前缘平滑降低至多 6% 不透明度。Launcher 后台串行捕获一个已接受全屏任务的静态硬件纹理：宽不超过 1024 像素，总像素约 210 万，单纹理约 8 MiB；取消中的结果加当前捕获，Java 可持有纹理上界约 16 MiB。安全 / HDR / protected、权限、几何、迟到或首帧透明度不适合时保留原生窗口。提交前网格持续匹配原生窗口的当前位置和圆角，等价帧已提交并隐藏原生 leash 后才从该位置开始变形。新触摸、打开、finish / cancel、息屏、布局 / 旋转、解绑及最多 1600 ms 截止撤销捕获并释放；岛体可再用至多 260 ms 完成有限回弹。旧回调不能改新窗口。只捕获一次，不持续更新应用画面。

## 通知接管

默认关闭、允许名单空；仅显式允许应用中，原生通过分组 / 排序 / 提醒规则且完成 Heads-up 绑定的标准文字 / 消息及有真实封面的图片通知可接管。保留通知中心原件；静默、DND、前台、排除 / 保留原生、敏感 / 应用锁、自定义、全屏、摘要、常驻、其他用户或失败保持 native。

独立 Keyguard 状态在接管前后检查，未知 / 异常拒绝；当前 Sbn / Row / entry / binding 与窗口成功才提交。未提交失败只回滚自己的状态，提交后 unbind 失败不重放提醒，旧同 key / 迟到回调不能清新通知。重复绑定不续 4 秒，点击交原生 Row，不另发 PendingIntent 或删除通知；只用内存公开内容和已加载图标，不读 URI / 数据库。详细安全、声明与频道合同见 [M03](../../rom-intelligence/M03_NOTIFICATION_CONTRACT.md)。

## 系统活动

匹配来源应用在前台时，该来源的持续活动不占岛；其他后台来源仍可正常显示。原生返回目标独立保留，真正回桌面后在同一岛体接入，避免前台实例与对应岛重复。

系统活动页按持续活动与即时反馈分组。通话、闹钟、倒计时、秒表、录音及隐私状态使用一份原生多选菜单，默认不选，仍写原有集合，不在页面进入后替换控件。短信、日历统一使用消息通知应用名单。时钟 / 录音需要框架作用域及对应应用重启。停用来源时，SystemUI 解除自身监听并清空对应当前槽。

时钟复用当前服务模型、响铃入口和自身秒表偏好变化；录音读取原生状态边沿与一次时长，不读文件名、文件或音频。显式选择的原生兼容录音机允许安装在用户应用区，仍按实际包 / UID 校验，点击使用其自身 Activity PendingIntent。两个来源各有一个匿名存活令牌，SystemUI 核验 Android 14 发送者、包 / UID / 用户、单调序号、短期时间戳、当前 owner nonce 和点击入口后接收。令牌只用于内核死亡通知，无命令接口；进程终止或 owner 替换解除 / 失效旧订阅，迟到死亡不能清新活动。

录音另有仅 SystemUI UID 可读的标量音量令牌。仅录制中、岛可见、录音机在后台、实时波形档且非省电 / 简化动效时，以最多约 15 Hz 读取原生峰值；五个最近音量构成包络，复用音乐波形最多 30 Hz 的平滑绘制，不冒充频谱。先按当前原生录音对象的 PCM 格式把 16 / 24 / 32 位峰值换算为统一 16 位量程，再进入 Binder 范围校验及固定平方根语音显示响应，先去除低于 256 的量化底噪，再应用公共显示增益。默认响应保留 15% 顶部余量，手动提高增益可达到柱顶。不从 WAV / M4A / MP3 文件后缀或编码码率推测量程，不按每次峰值做自动增益。静音先于增益归零，非有限或无效数值不产生柱高；细微变化过滤保留。

缓存的录音机 5.0.17.8 样本中，普通 WAV / MP3 为 16 位 PCM 峰值，高品质 WAV 为 24 位，M4A 使用 MediaRecorder 的原生峰值；MP3 的 75 / 100 / 192 kbps 在编码阶段应用，不改采集峰值量程。实现沿用原生标量 getter，只查看当前 AudioRecord 的格式或 MediaRecorder 类型，不读取 PCM、文件或编码缓冲。每次读取前后核验 Service、引擎及原生录音对象身份，切换不能沿用旧位深。仅字段解析元数据按当前引擎 Class 缓存一份，无电平 / 音频缓存；类替换淘汰旧项，未知格式不伪造柱高，计时保持可用。静音排空后停止无意义重绘；暂停、通知中心、前台、锁屏、解绑和设置关闭取消采样。没有新增录音权限、音频捕获或每帧广播。样本静态合同与实机各格式验收分开记录。

录音机的「录音时来电静音」由原生录音服务临时修改铃声模式，并在退出时恢复；其「录音中，静音模式已开启」是原生 Toast，不表示真实来电，也不改变采样增益。录音界面占前台时不显示对应录音岛，仍可显示即时静音反馈。离开界面时，当前录音会接管该界面已观察到的静音反馈及本应用 Toast；收集中的提示也不迟到抢占。后台迟到的录音机 Toast 保留原生位置，不再占岛。未屏蔽铃声广播，之后独立铃声变化和真实来电继续按原生来源处理；设备上的自动切换和极晚广播仍须录屏核对。

「上滑回岛」默认开启，仅对已选的通话、时钟、录音来源生效；首次安装 Launcher Hook 需重启桌面。复用媒体原生返回的任务、包 / 用户、单关闭目标、全屏、旋转及安全校验；每次原生返回独立编号，新打开 / 触摸 / 停用淘汰旧尝试，不依赖必须收到一个新的 DOWN。隐私和通知来源只使用共享进场 / 内容交接，不能因此重定向任意应用窗口。通话实际收回待实机通话验证，不影响 Telecom 原有操作。

通话复用受保护系统事件和 SystemUI 既有通话状态授权，只显示来电 / 通话并返回系统界面，不读号码、不自动接听。隐私活动读取原生 AppOps 已过滤的当前 / 最近访问列表，不把麦克风活动等同录音进度；保留原生隐私提示隐藏设置，自己的来源选择独立决定是否展示。媒体存在时只在同一个岛体的保留区显示小指示点。

短信和日历只接系统已经准许的标准提醒。短信使用消息语义；日历兼容标准日程 / 提醒类别以及已核实的四个原生提醒通道，未设 category 的真实提醒也可识别。沿用原生 Heads-up、免打扰、敏感 / 应用锁、前台、用户、排除及点击门禁，关闭通知后不另取正文，不读数据库补数据。

最多保存每类一个当前状态，无正文历史或活动队列。临时反馈 / 通知优先，随后依次为通话、闹钟、倒计时、录音、秒表、隐私，最后为媒体 / 小岛；同身份保持选择，上滑 dismissal 直到该来源结束。可见计时使用系统 Chronometer，暂停停表、隐藏 / 脱离停止更新，不用后台秒级轮询。倒计时归零与原生响铃交接最多保留三秒，早取消立即清除；不改原生声音、提醒、稍后提醒或传感器状态。

## 动画、实现与验收

同一 controller 的 FormState 持有当前来源、身份和形态；MotionCoordinator 按已提交的来源 / 身份 / 形态决定首次入场、原生窗口接入和内容交接，通知与媒体双向替换及同身份长短切换也走共同入口。同一形态的时长 / 元数据刷新不重播。来源不各建动画器。「上滑回岛」只控制原生窗口交接，不关闭系统活动自身进场。一个有限 ValueAnimator 时钟、五个标量通道描述宽高 / 位移 / alpha；封面翻转、内容淡入淡出、至多四档的模块文字模糊及横向二次拉伸沿用这个时钟，解析临界阻尼保留物理位置与速度。连续拖动接管当前呈现位置，使用平台 VelocityTracker 的近期速度，经与位移相同的有界阻力导数转换后交给弹簧。岛体围绕自身中心形变，纵向不随拖动平移；压缩渐近保留实际挖孔的最小遮罩高度，不再按摄像头中心移动整个岛体或硬夹纵向位置。松手沿统一 260 ms 有限欠阻尼时钟收敛。取消、多指、来源替换和 detach 回收输入采样，不启动常驻弹簧循环。顶部最终退出固定尺寸；新活动接替退出时保留可见位置并清除旧退出的向上速度。

首次进入采用 360 ms，来源 / 长短形态交接采用 300 ms 内容显现；顶边入场使用目标宽度，中心入场沿挖孔种子直接到目标。已有实例保留当前几何。仅尺寸变化按相对差在 220–320 ms 内变化，第二活动有明显尺寸差时上限 380 ms；等尺寸的新活动也有有界承接，纯元数据刷新不重播，普通内容更新 220 ms。专辑翻转至少 300 ms，淡出 / 淡入均受实际时钟限幅。越界回弹 260 ms，单独使用有限欠阻尼响应；退出 300 ms。原生上滑力度从时间加权的近期采样得到，包含合并历史，停留与反向输入衰减旧速度；超过 200 ms 的旧采样不再提供力度。两种 Home 效果由 ROM 的当前进度推进，保留其窗口速度与阻尼；完成 / 取消按租约恢复。吸入的岛体宽度先随真实页面后缘承接，90% 峰值后由同一有限时钟继续收敛；迟到的结束通道从当前宽度有限收敛，不重放入场。没有进度通道时沿当前岛体使用有限内容过渡，不直接跳到新尺寸。

媒体及已允许系统活动共用确认 Home 入口。原生窗口落点保持岛体宽度 84%、高度 86% 的同心范围；吸入网格的窄口水平居中、纵向位于实际岛体高度的 90%，岛体中心不跟随接入点下移。页面主体保留松手不透明度；全部网格进入真实岛体范围后，按剩余高度平滑让出纹理，露出真实岛色和透明度，避免结束时留下独立色块。普通通知 / 活动交接继续使用自己的有限内容过渡，重复确认不二次承接。点击当前可见的系统活动进入其应用时，已确认且未被主动关闭的后台播放会话在同一窗口立即接替，免去原有 750 ms 再入等待；仍异步核对原生会话。首次 / 新会话、暂停、遮挡、用户及来源排除继续沿原有准入规则。

中心动画从首帧保持最终高度与纵向位置，以同高圆胶囊横向展开 / 收回，只改变宽与 alpha，无上下回弹；左 / 右按选定边展开。上下模式保持高度，从顶部进退；内容增长从实际宽度连续变化。中断重入复用时钟并失效旧回调，简化 / 系统动画关闭直接设终态。摄像头和安全宽优先，摄像头种子尺寸不能在逐帧采样时撑大已选高度；图标、文字、波形反向补偿非等比变形，保留比例与 16 dp 边距，空间足够后出现。收短时封面容器不按目标内边距裁掉已补偿的封面，外层仍由同一 G4 岛体裁切。

实现和测试位于 `mods/island`。ROM 接入、会话 / 安全 owner、View / Motion / Sizing 分责，通用 Hook、安全、偏好与 StrongToast 快照仍在共享层。没有新增线程池、无界缓存、轮询或动画库。

Host 60 / 120 Hz View / Path 采样只验证连续性与比例，不是设备 FPS。尺寸、手势、native 返回、波形及通知设备项目归[路线图](../../maintenance/A14_REFINEMENT_ROADMAP.md#待实机验收)。历史设计研究、第三方参考与未复制代码 / 素材的说明可从[整合检查点原页](https://github.com/thetvplus/customiuizer-a14/blob/c9843589416efdbeba2d0f6d651c1c9e136e9fef/docs/features/island/README.md)恢复；时长和弹幅为本项目候选，不是 iOS 官方参数。

实时音乐采用原生归一化采集，避免低音量在 8 位 FFT 前被量化为零；它表达可视化信号起伏，不是客观响度计。FFT 源端过滤量化噪声，显示端不再先抛弃弱音乐频点。录音采用真实 S16 线性峰值，不做前置开方放大；公共增益随后平滑压缩，减少高增益时的平顶。实时采集不可用时保持静止，轻量模式仍保留轻量动效。

普通完成反馈若放不下短岛，会在同一来源租约下预检长岛是否能完整容纳，再一次进入长岛；仍无法完整容纳时保留原生提示。反馈结束释放自己的租约并恢复有效音乐，不清媒体槽。消息通知仍可抢占普通反馈，反馈不得抢占当前消息。

当前静态样本边界：TW Launcher 的 WindowElement / WindowAnimParamsProvider 路径已核对；POCO MiLauncherGlobal 的包名为 com.mi.android.globallauncher，其 Home 使用 QuickstepAppTransitionManagerImpl 直接创建 RectFSpringAnim，缺少 WindowElement。本次不把 MIUI 路径宽泛套到该宿主，POCO 保留原生返回；POCO 吸入适配与实机验收仍待完成。
参考运动研究： [SwiftUI Demo](https://github.com/stolyarenkoks/Dynamic-Island-SwiftUI-Demo) 以滚动位移映射头像尺寸、透明度与岛形态，并用 alpha 阈值和局部模糊表现融合；[Web Demo](https://github.com/fluid-design-io/ios-dynamic-island) 使用 layout / spring 联动尺寸，内容显现为 0.36 秒、零 bounce。两者的输入主要是滚动 / 点击状态，未提供 Android 原生 Home 判定或任务 leash 吸入。A14 借鉴单一几何、连续位置和先形态后内容的交接，保留 G4、ROM 时钟与当前有界资源所有权。
