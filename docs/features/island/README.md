# 动态岛

[页面功能地图](../../FEATURE_MAP.md) · [音乐手势与操作](MUSIC_GESTURES.md) · [待验收与证据](../../maintenance/A14_REFINEMENT_ROADMAP.md)

本页描述当前源码，后续分支能力不等于同版本正式 APK 已包含。适用平台见根兼容矩阵。

## 设置与兼容

入口为系统 → 动态岛；全局提示样式位于系统 → 系统提示。首次选动态岛模式及开启应用提示、媒体 / 通知接入后须重启 SystemUI；这些接入默认关闭。系统反馈逐类选择，新安装默认关闭；已启用动态岛且没有分类配置的旧用户保留原十类。已安装接入的分类、尺寸、动画与手势即时更新。普通 Toast 的位置、时间和过滤仍在系统 → Toast。

主页面只保留内容、外观动效和行为入口；音乐、消息通知、系统活动、位置尺寸各有子页。位置尺寸再按位置、高度、宽度分组，自动尺寸隐藏手动滑块。消息允许名单和保留原生悬浮相邻，排除优先；音乐子页集中波形、直接上岛与手势，原生 Preference 依赖统一管理启用状态。

页面迁移保持有效键、动作整数和 payload。旧展开宽度及已退役图标 / 状态 / 手势 / 控制键不再读取，设置启动时精确清理其短键 / 存储键，导入导出过滤，不清其他数据。新切歌开关 `system_island_media_swipe` 默认开启，不复用旧键。

`system_island_waveform_mode` 以字符串保存：0 关闭、1 轻量（默认）、2 实时。新键不存在时旧 waveform=false / true 映射 0 / 1，旧键仍可备份；显式新值优先，数字导入先规范类型，未知值回退轻量。旧备份在原子提交前迁移；旧模式 3 / 4 保留原反馈，部分新格式不补开遗漏分类。搜索使用真实子页及 System 控制器，保留摘要、依赖、面包屑和动作编辑。

## 形态、位置与输入

| 形态 | 内容 | 宽度 |
| --- | --- | --- |
| IDLE / 小岛 | 可选静止胶囊，下滑打开通知栏，点击无动作 | 自动以 100 dp 为基准，联动岛高与挖孔；或手动 48–120 dp，始终不宽于短岛 |
| SHORT / 短岛 | 封面 / 波形、头像、简短状态 | 40 dp 高度下自动首选 168 dp；手动 96–320 dp |
| LONG / 长岛 | 较多文字、可适配的应用 / 通知反馈 | 40 dp 高度下自动最多 218 dp；手动 120–400 dp，且不窄于短岛 |

展开后的长岛另按标题 / 详情和屏幕计算自动宽度：40 dp 高时以 300 dp 为基准、最高 352 dp，再让物理安全区限幅；手动长宽继续按用户配置。

三种形态共用高度与同一个窗口；自动高度按挖孔温和匹配 36–40 dp，手动仍为 32–64 dp，完整胶囊端帽。长度只改变中段。非默认的既有手动高度在自动键缺失时保留。自动宽度随高度温和联动，文字、图标、封面、波形与触摸几何同步适配。没有独立大卡片、详情面板或媒体按钮。

位置左 / 中 / 右，默认居中零偏移。横向滑块在 ±80 dp 上限内按三形态最小宽度、封面位置和挖孔连续限幅；靠左只提供向右调整，靠右只提供向左调整。左 / 右锚定安全边界，缩宽不移动选定边；遇挖孔只同侧缩宽，放不下时移至其下，不跳到另一侧。自动居中保持时钟 / 电量留白及至少 max(40 dp, 挖孔宽+16 dp) 的中间空隙；手动宽模式和主动展开允许时间、电量避让或隐藏，仍保留挖孔和物理安全边界。左右使用连续内容区，不受固定中间空隙或时钟 / 电量占宽限制。横屏沿用安全隐藏，回竖屏重读 Insets。

活动单击打开当前来源应用 / 播放器，通知交给匹配 Row 的原生点击。通知先入短岛，下滑或未绑定动作的长按可展开标题与正文；媒体未绑定下滑动作时可展开曲目信息，已配置音乐动作优先。长岛上滑先快速缩回短岛再退场；可选小岛在活动结束后继续静止显示。音乐动作、手势取消、单 / 双击仲裁和会话门禁统一见[音乐手势](MUSIC_GESTURES.md#输入会话与生命周期)。

一个固定宽度的透明状态栏画布容纳同一岛体，几何变化只更新岛体位置 / 形变，关闭原生窗口移动动画；Surface 使用对称 16 dp 外扩。同一窗口输入容器仅将岛体的动画区域和 12–16 dp 有界外扩写入 touchableRegion。没有第二个窗口或整条状态栏热区。上滑意图在点击分发前按原始坐标锁定，短于收起阈值也只回弹；快速释放补判缺失 MOVE，保留锁轴、多指取消和一次提交。窗口外通知栏 / 控制中心手势交原生。

## 展示与状态栏

`IslandActivityController` / View 共用一个模块窗口和身份租约：IDLE→PREPARED→VISIBLE→EXITING→IDLE。PREPARED 不占状态栏；有效布局、真实 attach、可见窗口、非透明内容、绘制区域及原生安全状态齐备后才取得占用，parent 非空不足以证明可见。通知中心展开时，活动沿同一时钟收为静止小岛，暂停波形和媒体采集并关闭热区，原生下拉不被截获；通知中心收起后复核当前会话再恢复。锁屏、息屏、其他遮挡、布局失败、取消 / 解绑成对释放，generation 拒绝旧退场移除新窗口。

按真实动画矩阵与屏幕偏移判定相交叶图标，小图标判定边界额外外扩 4 dp，黑岛实际边界保持；未相交图标、分组、顺序保持。时间、电量和 Duo 仅相交时避让；未知布局不退回整条淡出。至多记录 128 个当前叶项，布局时恢复 / 剔除离树项。隐藏约 320 ms，恢复约 400 ms；允许模糊且硬件绘制时使用有界临时图像 / RenderEffect，不覆盖既有 effect，失效释放；不支持回 alpha，简化 / 系统动画关闭直接完成。

小窗来源排除默认关闭，首次开启须完整重启设备；安装状态跨偏好刷新和 controller 替换保持。开启后按当前用户 / 默认屏幕的原生 PiP 组件、至多 16 项 freeform 包名及应用悬浮窗 UID 反选媒体来源。只有可确认属于小窗的媒体被排除，独立音乐、已允许的通知、普通提示、系统反馈和小岛继续按原有规则显示。未知来源不扩大为全局隐藏；原生 PiP / Home 事务仍保护对应视频的返回动画。系统来源广播仅传有界身份和时序，不传标题、音频或窗口对象；绘制前只读已发布的标量快照，无逐帧查询。

## 系统与应用反馈

十类为勿扰、铃声、深浅色、飞行、NFC、热点、手电、Wi-Fi、移动数据、蓝牙；仅选中类别注册监听，关闭释放并丢弃对应待显示项。只报告真实终态，不把初始 / 重复 / 过渡态写作成功。单个最新槽收集 200 ms；控制中心展开时不绘制或占状态栏，收起仅显示仍有效最新项。事件总寿命 6000 ms，展示不超过剩余期限；锁屏、切用户、超时、owner 销毁即丢弃。

350 ms 内由勿扰引发的铃声变化、飞行引发的无线关闭仅留主反馈；原生 AudioManager 指令 / 磁贴仍识别独立操作并解除因果合并。不再拿插件第二份提示作另一来源。

动态岛模式在 StrongToastControl 统一显示入口结束请求，不创建原生额头窗口 / 动画队列，不保留透明窗、原生图标改写或未知内容回退。独立 MiuiChargeController / MiuiChargeAnimationView 仍由系统管理，锁屏大充电动画保留。充电和低电量分别选择，默认关闭；启用后只监听电池终态边沿，初始 / 重复快照不提示。低电量采用 20% / 10% / 5% 阶段；只有替代岛可见后，才发布最长四秒的临时确认，让安全中心沿既有设置读取抑制底部弹窗。未显示、迟到 / 失败写入、隐藏 / 释放均保留或恢复 native；不持久改变系统低电量选项。首次启用低电量接管须重启系统界面和安全中心。系统默认与匹配高度模式继续保留原生行为。

普通 Toast 仅接完整、无格式、单行且能放下的文字；明确成功 / 保存路径可精简，其余原文。长文、自定义、空间不足、副屏、安全来源缺失或挂窗失败保留原生反馈。

封面、头像、图标和明确成功状态精简为固定行为。十类图标按固定名称白名单读取 ROM；勿扰 / 静音优先挂载插件四个提示资源，其余用 SystemUI 原生开关含主题覆盖，再缺失用 Android 信息图标。不加载插件代码或持有其 controller / Context。事件独占 Drawable，白色对比；冷路径至多 96×96 临时画布测透明留白，立即释放，归一到 24 dp 单元中约 20 dp 可见图形且保持比例。失败保留素材，不手绘 / 重画；空间完整后才显示。

## 音乐与原生返回

正常跟随系统选中的主播放器；小窗来源反选命中后，至多保留一个曾由系统选中过的独立播放器作为候选，不保留其封面、不增注册回调；每次使用前重新核实当前用户、真实 PLAYING（已显示的同一会话加载中可静置保留）和排除规则，主动收起、失去 native owner、安全失效或销毁即清除。进来源 App 隐藏，离开复核真实状态，普通播放入场等 750 ms。在途首份读取也受前台变化 / generation 失效，native owner 丢失清媒体；仅同一已显示加载会话的短暂原生卡片缺失可由现有会话回调继续持有，旧 PLAYING 不能复活。

明确 BUFFERING / CONNECTING / SKIPPING 时保留现有封面和标题，波形停钟、释放采集；实际 PLAYING 后只交接一次最新曲目。不对明确仍加载的有效会话使用普通暂停超时，也不轮询。加载后仅收到 PAUSED 的含糊中断最多等待 30 秒，重复快照不续期；首次只有加载状态不新建音乐岛。STOPPED / ERROR、会话销毁、来源或安全失效仍立即清理。

暂停保留、预绘制证据与会话释放统一见[音乐手势的暂停可见性合同](MUSIC_GESTURES.md#暂停可见性)。上滑 dismissal 绑定同 session，换曲 / 旧快照不撤销，真实暂停 / 恢复边沿才激活；控制中心暂挡不重置期限。

音乐直接上岛默认关闭、名单空，启用并选择 App 后须首次重启 Launcher。只接受当前用户、竖屏、单一标准全屏任务 CLOSE_TO_HOME，包 / 任务 / session 一致；最近任务、快速切换、分屏 / 小窗、横屏、非名单或未知保持原生。

复用 Launcher WindowElement / RectFSpringAnim；在原生查找桌面图标之前选择无图标目标，提交返回时复制 RectFParams，只改应用窗口目标、圆角和无图标标志，原参数不变。迟到快照不得接管已经选中的桌面图标；不借用、快照或隐藏桌面图标。窗口 Surface、速度、进度及 finish / cancel 仍由 native 持有，不截图或另造封面层。

仅 native 实际采用终点、原调用成功且动画运行才确认；SystemUI 80 ms 复核后用 560 ms 有限接入动画，无确认保留 750 ms。每次最多一个 token 候选，750 ms 失效，metadata 不重播。关开关 / 撤名单、二次切 App、暂停 / 换会话、隐私、通知抢占、owner 失效撤销；未入场恢复原截止时间。简化或系统动画关闭跳过动效。

真实 Home 边沿对离开的应用做一次至多 16 项的任务查询，声明自动 PiP 的候选等待对应原生任务稳定或取消后才应用展示策略。每个 controller 只保留一个意图、串行查询和 2.5 秒兜底；独立 Shell 入场请求绑定单个 token，原生状态、取消、owner 替换或五秒截止清除。普通音乐查询无候选即放行，不统一增加动画延迟。

显式消息核验 Android 14 发送者，仅传选中包 / 用户 / 几何 / 短期时间戳，不传标题 / 封面 / 音频。Launcher 在 DOWN、选中应用的原生打开动画时异步刷新，SystemUI 在选中播放器的真实前台边沿续发；每份新快照最多保存五秒，成功提交异步确认一次。Receiver / scope 随开关、NavStubView 和岛 controller 注册释放；无 MOVE / 每帧 IPC、轮询或额外 Bitmap。

实时波形默认关闭，默认轻量只表示播放。共享 FFT 映射五柱，采样遵循 ROM 上限（当前实机为 20 Hz），攻击 / 释放按实际时间平滑并过滤细微变化和量化噪声；显示层按约 30 Hz 插值，仅五柱变化期间刷新，静音 / 稳定后停止时钟，不修改屏幕全局刷新率。仅可见播放、非简化 / 非省电、当前用户的本地选中播放器 UID 可采集，拒绝远程、通话、全局 session 0 和跨应用 / 用户音轨。HyperOS 可为 Telegram 复制媒体会话；选中 token、包、UID / 用户须相符，会话数量不再当作音轨数量。同应用多媒体音轨优先固定当前 session，停播后才按稳定顺序重选，其他应用的音轨不会参与。更换同应用会话时短暂保留最后一帧，首帧失败 / 超时回轻量，不循环重试。FFT 不保留 / 记录 / 上传，隐藏、暂停、息屏、换用户或关闭即失效并释放；不新增 / 申请录音权限，仅复用 SystemUI 既有权限。SystemUI 原生权限 / AppOps / Visualizer 不可用时仍回退。

## 通知接管

默认关闭、允许名单空；仅原生通过分组 / 排序 / 提醒规则且完成 Heads-up 绑定的标准消息及有真实封面的图片通知可接管。保留通知中心原件；静默、DND、前台、排除 / 保留原生、敏感 / 应用锁、自定义、全屏、摘要、常驻、其他用户或失败保持 native。

独立 Keyguard 状态在接管前后检查，未知 / 异常拒绝；当前 Sbn / Row / entry / binding 与窗口成功才提交。未提交失败只回滚自己的状态，提交后 unbind 失败不重放提醒，旧同 key / 迟到回调不能清新通知。重复绑定不续 4 秒，点击交原生 Row，不另发 PendingIntent 或删除通知；只用内存公开内容和已加载图标，不读 URI / 数据库。详细安全、声明与频道合同见 [M03](../../rom-intelligence/M03_NOTIFICATION_CONTRACT.md)。

## 系统活动

系统活动页分持续活动和即时反馈。持续活动使用一个类型多选，默认不选：通话、闹钟、倒计时、秒表、录音、隐私活动、短信通知和日历通知。时钟 / 录音需要框架作用域及对应应用重启；首次增加原生来源后重启手机。停用来源时，SystemUI 解除自身监听并清空对应当前槽。

时钟复用当前服务模型、响铃入口和自身秒表偏好变化；录音只读原生状态边沿与一次时长，不读文件名、文件或音频。两个来源各有一个匿名存活令牌，SystemUI 核验 Android 14 发送者、包 / UID / 用户、单调序号、短期时间戳、当前 owner nonce 和点击入口后接收。令牌只用于内核死亡通知，无命令接口；进程终止或 owner 替换解除 / 失效旧订阅，迟到死亡不能清新活动。

通话复用受保护系统事件和 SystemUI 既有通话状态授权，只显示来电 / 通话并返回系统界面，不读号码、不自动接听。隐私活动读取原生 AppOps 已过滤的当前 / 最近访问列表，不把麦克风活动等同录音进度；保留原生隐私提示隐藏设置，自己的来源选择独立决定是否展示。媒体存在时只在同一个岛体的保留区显示小指示点。

短信和日历只接系统已经准许的标准提醒。短信使用消息语义；日历兼容标准日程 / 提醒类别以及已核实的四个原生提醒通道，未设 category 的真实提醒也可识别。沿用原生 Heads-up、免打扰、敏感 / 应用锁、前台、用户、排除及点击门禁，关闭通知后不另取正文，不读数据库补数据。

最多保存每类一个当前状态，无正文历史或活动队列。临时反馈 / 通知优先，随后依次为通话、闹钟、倒计时、录音、秒表、隐私，最后为媒体 / 小岛；同身份保持选择，上滑 dismissal 直到该来源结束。可见计时使用系统 Chronometer，暂停停表、隐藏 / 脱离停止更新，不用后台秒级轮询。倒计时归零与原生响铃交接最多保留三秒，早取消立即清除；不改原生声音、提醒、稍后提醒或传感器状态。

## 动画、实现与验收

一个有限 ValueAnimator 时钟、五个标量通道描述宽高 / 位移 / alpha；封面翻转、内容淡入淡出、至多四档的模块文字模糊及横向二次拉伸沿用这个时钟，解析临界阻尼保留物理位置与速度，改目标不重置速度。进入 360 ms；形变按相对尺寸差在 220–320 ms 内变化，第二活动有明显尺寸差时上限 440 ms。相近尺寸只作 220 ms 内容交接，不加回弹；专辑翻转至少 300 ms，淡出 / 淡入均受实际时钟限幅。取消 280 ms、退出 300 ms。长岛退出先用 150–160 ms 收回短宽；原生上滑力度只在已提交的返回中携带一个有界值，入岛时长最多微调 35 ms，横向响应微调，不改原生窗口速度 / 进度。

中心动画从首帧保持最终高度与纵向位置，以同高圆胶囊横向展开 / 收回，只改变宽与 alpha，无上下回弹；左 / 右按选定边展开。上下模式保持完整宽高，从顶部进退。中断重入复用时钟并失效旧回调，简化 / 系统动画关闭直接设终态。摄像头和安全宽优先；图标、文字、波形反向补偿非等比变形，保留比例与 16 dp 边距，空间足够后出现。

实现和测试位于 `mods/island`。ROM 接入、会话 / 安全 owner、View / Motion / Sizing 分责，通用 Hook、安全、偏好与 StrongToast 快照仍在共享层。没有新增线程池、无界缓存、轮询或动画库。

Host 60 / 120 Hz View / Path 采样只验证连续性与比例，不是设备 FPS。尺寸、手势、native 返回、波形及通知设备项目归[路线图](../../maintenance/A14_REFINEMENT_ROADMAP.md#待实机验收)。历史设计研究、第三方参考与未复制代码 / 素材的说明可从[整合检查点原页](https://github.com/thetvplus/customiuizer-a14/blob/c9843589416efdbeba2d0f6d651c1c9e136e9fef/docs/features/island/README.md)恢复；时长和弹幅为本项目候选，不是 iOS 官方参数。
