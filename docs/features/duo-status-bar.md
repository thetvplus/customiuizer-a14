# Duo 三合一图标

适用于 HyperOS 1 / Android 14。入口：系统 → 状态栏 → Duo 三合一图标。默认关闭；修改设置后重启系统界面。

外圈显示手机电量，顶部显示百分比或充电闪电，中间显示网络或短时耳机图案，下方四点显示默认数据卡的蜂窝强度。状态栏、锁屏和控制中心沿用相同信息。

## 大小与颜色

自动大小沿用原生图标高度的既有校准曲线，将此前可见大小再增加约 0.5 dp，布局与绘制共用最终的整数像素尺寸。实际绘制仍受宿主可用行高约束，结合环体与顶部字形可见范围限制偏移，控制中心交接保持源行尺寸；关闭后可手动设置 20–40 dp。默认居中，垂直微调 ±4 dp、每档 0.5 dp，偏移与绘制范围受行高约束。左右间距默认每侧 1.5 dp，可在 0–6 dp 间按 0.5 dp 调节，不改变图形尺寸。可选加粗。百分比、尺寸与微调独立于原生电池样式。

普通前景跟随原生颜色和透明度；充电绿色、省电黄色、低电量红色。充电闪电与百分比沿用同一光学高度和中心，路径在绑定前准备，不逐帧测字或缩放。充电闪电独立开关默认开启；显示百分比且电量为 100% 时按原生条件隐藏闪电，关闭百分比时仍可显示。关闭闪电且开启百分比时，充电显示绿色数字；两者都关闭时，充电显示顶部连续的绿色圆环。未充电且关闭百分比时，上方圆环保持连续。修改后需重启系统界面。

## 网络

- Wi-Fi 一格显示底部，二格增加内弧，三 / 四格增加外弧；淡色部分是轨道。
- Wi-Fi 未连接时默认显示蜂窝或无服务图案；关闭断连替代则恢复淡色 Wi-Fi。蜂窝图案表示有服务，不能保证互联网可用。
- 蜂窝中心可选图形或 2G / 3G / 4G / 5G 文字。仅 Wi-Fi 未连接且蜂窝有服务时生效；4G+ / LTE 归为 4G，5G+ 归为 5G，未知类型回退图形。文字复用下述获许可圆体子集，仍按实际字形测量。
- 下方信号点跟随默认数据卡。0–5 六级信号用部分点亮区分全部档位，无服务 / 飞行模式清空点亮。
- Wi-Fi 网络异常优先于耳机提示；无 Wi-Fi 的飞行模式优先显示飞机。

## 耳机短提示

有线耳机或蓝牙音频新连接提示 3 秒，然后恢复网络图案。初始同步、重复事件与重新打开控制中心不延长或重播；持续连接不常驻占用中心。

耳机样式可选自动、头戴、耳塞，大小 85–115%。自动模式下蓝牙用耳塞、有线用头戴，不识别具体型号。

启用电量颜色且系统报告明确的单个蓝牙设备电量时，≤20% 为红色、≤50% 为琥珀色，其余跟随原生颜色。缺失 / 多设备信息不推断满电，有线耳机不显示虚构电量；外环始终是手机电量。样式、大小和电量颜色依赖耳机提示开关。

## 过渡与回退

中心轮廓变化使用逆向默认 response .50、damping 1 的同事务淡出 / 淡入，Wi-Fi 同步中心缩放；最多保留前后两种轮廓，连续改向继承当前值。Wi-Fi 强度与耳机电量颜色直接更新，蜂窝四点使用同一原生默认参数。省电或系统关闭动画时直接切换；过渡中关闭动画，下一次绘制提交最新完整图案，不再请求过渡帧。快速变化不叠加动画，隐藏时停止，静止时无持续刷新。控制中心移动使用系统宿主动画。

接口不兼容或运行异常时恢复原生显示。采用 Android 原生绘制，不增加动画运行库、轮询服务或后台线程。短时验证不能外推到全部 ROM、耳机或长期耗电。

设计证据优先采用本地同构建 Duo 24B91020 逆向资源及消费者。Wi-Fi 沿用三份同拓扑 CoreUI master 的既有离线插值结果，默认 bold/medium 与额外加粗 black/medium 的坐标转为直接 Path 命令；运行时不解析路径字符串、读取图片或重新插值。原生 Wi-Fi 主项在辅助飞机旁采用字号请求 15 / top13，其余当前可表达分支采用 16 / top(14+1.33)；辅助飞机在实测主项底缘加 1，主项为空时使用固定 top30。Android 按当前矢量框提供测量适配，字体请求不等于可见墨迹宽度，不称一比一。未知热点 / 共享状态不由断网自行推断。

Wi-Fi 以 0、.34、.68 阈值选择完整亮色或既有淡色轨道，Android 五档输入映射为四种稳定轮廓，三 / 四格同为完整三段；最低有效信号的底部扇形保持完整亮度。整体框只缩放一次，顶部电量组合与底部四点各保留自己的槽位，按可见范围限制宿主行内的偏移。几何准备复用固定 Path，静止时无新增刷新。

## 图形与兼容边界（2026-11-06）

以 iPhone Duo / 24B91020 的整体框与槽位为基准，不应用 19.5% 纵向改位。新交付的纯代码库补齐原始 BVG 矢量：飞机、耳机、AirPods、异常 Wi-Fi 和填充闪电已替换原遮罩等值线近似，直接构造共享 Path。当前明确采用 CoreUI 原始 key26=4 的中间 master，不把它等同于 SwiftUI weight raw4 或声称已经恢复 UIFont 插值。异常 Wi-Fi 保留各个可见 peer，原 opacity=0 的层不绘制；合并轮廓会改变相交边缘的抗锯齿，因此不以 union 减少这些原始绘制层。

离线无服务图案仍是项目扩展，保留原遮罩派生路径；只有这张遮罩保留在 JVM 回归资源。其余旧小图随已被替代的生产对象移除，测试改为直接对照原始矢量命令、变换与透明度。转换入口为 `tools/generate_duo_symbols.py --native-glyphs <private-export>/glyphs/glyphs.json`，输出生产命令与测试用源模板；运行时不读取该 JSON。所有符号仍按需准备并共享，闪电绘制和圆环挖空共用同一原始轮廓，不按分辨率制作位图。

状态仍由原生网络 / 订阅回调驱动，双 SIM 依据默认数据订阅选择，退役 controller 回调不能覆盖新卡。未知状态保留原图标；飞机模式、无 SIM、Wi-Fi 与耳机优先级沿既有状态机处理。反射改为完整参数 / 返回类型匹配，SystemUI ClassLoader 只冷解析；音频与控制中心仍是独立可选边界，必需合同缺失回退。静态样本与设备覆盖分开，见路线图及 `duo_statusbar_contract.sql`。

47 点整体框与宿主行中心对齐，仍保留用户手动偏移。耳机提示与无服务扩展按各自轮廓面积重心居中，耳机保留用户 85–115% 范围；Wi-Fi / 异常 Wi-Fi 改用已取证的父布局 top 与条件字号，不能再把所有状态强移到同一个纵向中心。主蜂窝单行使用 top17、2.67 宽、1.67 间距及 6…10.33 高度；下方四点保留独立弧布局。电量组合保持顶部槽位。面积重心和矢量框到宿主的映射均为 A14 适配，不冒充完整 SwiftUI 字体度量。

普通状态栏圆电池的 peer 放置、创建、状态和绘制调用链已经补齐，不能继续标为仅有 HUD 旁证。UIKit 的 size47 / inset4.66 / thickness3.33 与 SystemStatusUI 的 ringDiameter38 分别保留各自所有者。圆环采用原四段贝塞尔 `k=.5522847498`，轨道与电量各旋转一次 +π/2；按曲线长度的 1/6…5/6 裁切，由 Android PathMeasure 测长。该平台适配不宣称与原 RenderBox 测长、栅格化逐像素相同。

新库的数字轮廓默认 `wght=400 / wdth=100`，不等于当前 App 的 Heavy（wght858.4 / GRAD400）实例。当前数字与网络标签改用 OFL-1.1 许可的 Nunito 900 最小子集（修改后名为 A14 Rounded Heavy），替代无再发行依据的 Apple 字体；相同字符集、字号、Paint 与测量布局继续复用。尚未把数字代码或全部 27 类 / 81 个模板引入 App。原生最终字体轴、完整度量、实际 screen trait 与颜色解析仍有缺口，不能宣称当前 App 已经完全无字体文件或像素级复刻。

整体自动尺寸以此前实际可见体量为基准再增加约 .50 dp；原二次墨迹缩放归入这一次整体尺寸计算，最终取整数像素，布局占位与绘制使用同一整数值，不保留两位小数 dp。受像素舍入及宿主行高度约束，实际增量有半个像素的误差；手动尺寸继续直接消费用户设置。

## 单项定位与字号映射校正（2026-11-06）

普通 Wi-Fi 的可见轮廓与圆环共用中心，Wi-Fi＋飞机保留 iPhone 的 15 点／顶部 13 分支及实际底缘加 1 的辅助项规则。原来的字号到固定墨迹宽度映射遗漏模板的 17 点参考尺度；现在按原有 bold/medium 或 black/medium 轮廓做一致比例变换，不更改原始曲线，也不缩成 Mac 参考的图形比例。警告 Wi-Fi 单项同样归回圆环中心。

原生 top 参数属于测量后的符号框，不能直接当成 Android Path 的墨迹顶部。原版未闭合的单项光学定位采用 Status Trio [v1.9.3](https://github.com/lingyired/status-trio/releases/tag/v1.9.3) 的可见墨迹对齐方法；圆环尺寸、字体请求、Wi-Fi／飞机比例和两遍组合继续来自 iPhone。Status Trio 的 119 宽画稿、绝对坐标和较小 Wi-Fi 比例不直接迁入。

整体仍只有一次整数像素映射，保留已授权的约 .50 dp 增量与手动尺寸／偏移。Host 验证原始轮廓、两种字重的水平／垂直中心、强度更新、组合间距、隐藏释放及设置导航；目标 fuxi 的最终画面另作验收。

## 字体来源与再发行

圆体来自 [Google Fonts 的 Nunito 固定源码](https://github.com/google/fonts/tree/38411257417e616c5d4daa1b9e91a3dbcebe1c2e/ofl/nunito)，版权归 The Nunito Project Authors。以 fontTools 4.63.0 固定 wght=900，仅保留 `%+0123456789EGLT`，修改族名为 A14 Rounded，并保留版权和许可元数据。完整 OFL-1.1 随 APK 位于 `assets/licenses/Nunito-OFL.txt`。这是 Android 上的相近圆体，不宣称 SF UI Rounded 或原生字体像素等价；未增加绘制时加载、网络下载或字体监听。
