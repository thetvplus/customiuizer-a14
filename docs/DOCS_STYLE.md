# 文档维护规范

文档解释必要约束；开发历史由 Git 保存，不要求每次修改都写维护报告。

## 单一事实来源

| 事实 | 权威来源 |
| --- | --- |
| UI 入口、名称、顺序和条件 | 当前 XML、资源、路由及 Controller |
| 实现、安装与所有权 | 当前源码、Feature catalog；进程矩阵只作生成视图 |
| 当前功能导航 | [FEATURE_MAP.md](FEATURE_MAP.md)；[字符树简版](FEATURE_MAP_SIMPLE.md)为同源生成视图 |
| 当前问题、决定与待验收 | [精修路线图](maintenance/A14_REFINEMENT_ROADMAP.md) |
| 平台与 ROM 支持边界 | [COMPATIBILITY.md](../COMPATIBILITY.md) |
| 发布安全、操作和恢复 | [RELEASE.md](RELEASE.md) |
| 执行分级、验证选择、复用和停止条件 | [TESTING.md](TESTING.md#执行分级) |
| 历史发行变化 | [中文 CHANGELOG](../CHANGELOG.md) / [English CHANGELOG](../CHANGELOG_EN.md) |
| ROM 取证 | 实际样本身份、哈希和[原始证据来源](rom-intelligence/README.md) |

其他文档直接引用对应来源，不复制完整合同。根 README 只介绍产品、主要能力、安装与下载 / 开发入口；本目录 [README](README.md) 是唯一文档总目录。

## 何时更新

- 页面、设置键、资源名称或路由变化：复核条件说明，运行 `python tools/generate_feature_map.py`。
- 地图复用偏好生成器的分类 / 子页注册和搜索解析，不手写第二份完整页面或 Feature 清单。
- Hook 契约变化：只更新受影响的专项说明；复杂状态机、安全和生命周期合同仍需保留。
- 兼容范围变化：更新兼容矩阵；发布流程变化：更新发布文档。
- 普通 Bug：通常保留提交、测试和必要 Issue 即可；影响发行用户行为时更新双语未发布记录。
- 精修路线图只更新仍有效的决定、未决问题和必要证据入口，不追加阶段流水账。

## 何时删除

- 可删除纯跳转页、无独立职责的中间索引、重复说明和过期临时计划。
- 可删除失去实际消费者的生成文档，以及已被准确替代的旧功能说明。
- 删除前检查 Markdown、源码注释、生成器、测试、工作流和模板的全部引用与依赖。
- 内部链接直接改到有内容的目标；仓库外历史链接不要求永久保留空壳页。
- Git 历史足以保存的内容不另建长期归档；必要证据引用提交 SHA 与历史路径。
- 不为降低行数删除发布安全、恢复、兼容或 ROM 来源证据。

## 写作与验证

- 文件名统一英文，默认中文用主文件名，英文副本用 `_EN` 后缀（如 `CHANGELOG.md` / `CHANGELOG_EN.md`）。通用入口用大写加下划线，专题用小写短横线，目录小写；保留 README / AGENTS / SKILL 等约定和既有稳定路径。
- 中文文档标题与目录显示名用中文，技术 / 产品专名保留原名；英文 README / CHANGELOG 保持英文。不在同一标题并排中英文译名。
- 简短、准确、可检索；标题说明具体职责，文件名稳定。
- 使用真实路径、符号和设置键；不复制源码解释显而易见的行为。
- 公开问题、实机场景和外部参考按功能 / 窗口类型描述，不写使用者的第三方应用名、包名、样本文件名 / 哈希、账号、设备序列号、密码、专网地址或个人配置；精确关联保留在仓库外证据。平台 / ROM 契约必要的组件名称、公开样本身份与许可归属按实际需要保留，公开功能入口和资源链接不透露个人使用情况。
- 区分已实现、源码 / 构建验证和实机待验收；推断明确标注，不把历史样本写成当前设备结果。
- 不用阶段性总结代替产品说明，不制造重复原文的中文版技术文档。
- 文档改动按 [TESTING 的 Quick 文档范围](TESTING.md#执行分级)检查，不重复维护命令清单。
- 生成器 / Python 工具变化补跑工具测试；页面 / 运行时生成合同变化仍需对应专项回归。
- 链接检查覆盖仓库 Markdown 的本地目标、锚点和图片；不声称已验证外网可用性或设备功能。

## Agent 按需阅读

新 Agent 默认只读 [AGENTS.md](../AGENTS.md) 和当前任务真正涉及的文件。
功能入口先读字符树简版，设置键或条件再查详细地图；文档治理按需读本规范，不递归加载整个文档目录。
AGENTS 只放简短入口，不复制本规范或另建第二套文档规则。
