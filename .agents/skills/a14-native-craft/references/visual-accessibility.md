# 视觉与无障碍

用于设置行、岛内容、状态栏信息、Dock 材质或可访问交互；动效时序另见 [动效与输入](motion-input.md)。

## 视觉判断

- **层级先于装饰。** 先读出主信息、补充说明、当前状态与可操作对象，再判断字重、颜色和留白。沿用 A14 / 宿主的字体与资源，不因 Web 参考提倡“个性”就换字体、下载字库或增加品牌化视觉。
- **基线与密度。** 用现有 dp / sp 转换和字体度量检查图文基线、数字宽度、内边距及截断。核验中文、拉丁文本、emoji、RTL、长标题和大字号；不能用缩字解决所有溢出，也不能因视觉居中破坏实际触摸位置。
- **材质服务可读性。** 在深浅色、亮暗壁纸和关闭模糊时分别检查前景。不要叠加多份填充来增加“玻璃感”；材质失败的回退以功能合同为准。装饰不能掩盖控制状态或改变图标位置。
- **一致但不强制同形。** 层级相同的项保持节奏；不同语义不机械套相同卡片、阴影和圆角。设置行的名称、说明、右侧值及复用语义以 [设置合同](../../../../ARCHITECTURE.md#设置生成与持久化) 为准，不在此维护第二套布局规范。
- **状态可辨。** 按下、选中、禁用、等待、失败和空内容有可理解的表现；不要只靠颜色或播放动画表达结果。操作名称、反馈文案与实际终态相符。

## Android 可访问性

优先保留 TextView / Preference 原生语义。自绘内容按实际角色补充 AccessibilityNodeInfo；一个 Canvas 中含多个独立操作时才评估虚拟节点，读取顺序、边界和动作必须与可见内容一致。纯装饰不加入焦点序列；隐藏或已退出的旧内容不继续播报。文字本来已被读取时，避免重复 contentDescription。

普通设置控件按 Android 的 48 dp 触摸目标建议检查，可用既有布局留白容纳目标；这是交互区域建议，不是把所有图标画成 48 dp。系统覆盖层不能为了达标扩大拦截区、改变状态栏手势或突破岛现行触摸合同：记录实际可访问性缺口，优先利用已有可访问入口和动作；改动命中范围须单独验证功能边界。

文字对比参考 Android 当前标准：较小文字至少 4.5:1；达到官方大文字条件时至少 3:1。玻璃 / 壁纸背景检查实际合成结果，不仅比较资源色值；无法获得像素或渲染证据时标为待验。字号使用系统缩放，检查换行、基线和裁切，不另行固定 scaledDensity。

触摸自绘点击沿用 performClick / 可访问动作路径；拖动或长按等复杂手势有等价的可访问操作。检查 TalkBack、键盘 / D-pad 焦点与 RTL；未运行这些交互，不宣称已通过。

减弱动态和系统动画关闭沿用现有 Android / A14 策略；系统比例为零时直接提交正确终态并清理资源，不再补一段淡入。较温和模式可按现有合同减少形变、弹性和重复运动。触觉只在有意义的提交点按系统偏好使用，不作为唯一反馈。
